# Campus ReUse – Student-Centric Second-Hand Product Marketplace

A responsive frontend prototype for a college student marketplace.

## How to run
1. Download and extract the ZIP file.
2. Open the extracted `Second_Hand_Product_Marketplace` folder.
3. Double-click `index.html` to open the website in a browser.

## Features
- Browse sample second-hand products
- Search products by name, category, or description
- Filter by category and sort by price
- Add a product listing with name, category, price, description, seller contact, and optional image URL
- Saves added listings in the current browser using local storage
- Responsive layout for mobile and desktop

## Important note
This is a frontend demonstration prototype. It does not include a real user login, server, shared database, or online hosting. Listings are stored only in the browser where they are added. To make it a live multi-user website, connect a backend and database and deploy it to a hosting service.
